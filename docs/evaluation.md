# 作业二 · RACE／FACT 与榜单口径

**本次未运行、未提交正式 RACE／FACT；没有正式分数。** 整理口径是解释别人如何评测，不是说我们已经测过。

| 机制 | 它主要问什么 | 本包有什么 |
|---|---|---|
| HyperResearch verify | 报告文件、标题、长度、引用密度、指定产物等是否满足本地规则 | 一次真实失败 JSON；不是 RACE |
| RACE | 目标成品报告相对于参考报告，全面性、洞察力、指令遵循、可读性四维的加权评价 | 只说明协议；未调用评审模型 |
| FACT | 去重后的陈述—引用地址对，能否得到对应来源支持 | 只说明协议；没有网页复抓和正式评分 |
| 六步课堂实验 | 给定候选、片段、字段和值是否匹配；预算／停止是否明确 | 冻结资料小实验，不是官方基准 |

DeepResearch Bench 的评测对象是成品报告，不是完整 Agent 轨迹。官方任务集有 100 道题，50 中文、50 英文，覆盖 22 个领域；约 96,147 条实际查询用于研究需求分布，不能说我们的一个自选房产问题就是官方测试集成绩。[官方论文](https://arxiv.org/abs/2506.11763)、[官方仓库](https://github.com/Ayanami0730/deep_research_bench)

课程说明：RACE 的参考报告来自 2025 年 4 月 Gemini-2.5-pro Deep Research，不是人工专家范文。评审模型、权重、参考报告和协议版本会影响结果；单个得分不等于“事实正确率百分比”。FACT 需要能够获取引用页面的服务条件；抓取失败／未知支持不能凭语气填成 supported。此处不捏造官方运行命令、指标分母或分数。
